code (section 6) does not grant trademark rights, and this file says what is fine without
asking.

## Fine without asking

- Using the name to refer to this project, including in articles, talks, package
  descriptions and comparisons.
- Saying that something is "built on Replaybook", "compatible with Replaybook" or
  "a Replaybook pack", when that is true.
- Keeping the name in an unmodified copy, a fork used inside your own organisation, or a
  fork whose changes are offered back to this project.

## Please rename

- A modified version distributed to others as a product or a service. Call it something
  else and say it is derived from Replaybook if you like.
- Any use that suggests the project or its author endorses, supports or is responsible for
  your product, service or organisation.

## Anything else
